    Boundaries of this build

    • Evidence is kept

      Runs, dataset fingerprints and analyst reviews are stored in a local SQLite database.

    • Tools are simulated

      Reference agents can request tools; no money moves and no emails or records change.

    • Not a hardened code sandbox

      Do not run untrusted agent code. Your agents must run in isolated staging with dangerous actions disabled.

    • Not multi-tenant

      One operator on one computer. There are no user accounts or customer separation.

    • Not insurance advice

      Dossiers and slips are non-binding technical evidence. No rating, quote, placement or coverage decision.
